## 6. Checkpoint 5: Deterministic Product ID & Base Plan ID

### Question:
*Identify the exact subscription product ID and base plan ID generated by the existing code for a newly created subscription plan.*

### Finding:
The existing code in `playSkuHelper.ts` generates deterministic IDs based on the plan's database UUID and its billing cycle.

### Deterministic Mapping Rules:
- **File:** `C:\Projects\MockTestApp\src\utils\playSkuHelper.ts` (Lines 48–72)

```typescript
export function getSubscriptionPlanPlaySku(planId: string, _billingCycle?: string): string {
  const clean = uuidToCleanHex(planId);
  return `sub_${clean}`;
}

export function getSubscriptionBasePlanId(billingCycle?: string): string {
  switch (billingCycle?.toLowerCase()) {
    case 'quarterly':
      return 'p3m';
    case 'half_yearly':
      return 'p6m';
    case 'yearly':
    case 'annual':
      return 'p1y';
    case 'monthly':
    default:
      return 'p1m';
  }
}
```

## 10. Step-by-Step Instructions to Test the First Subscription

Follow this exact sequence to configure and test the first subscription product:

### Step 1: Create a Subscription Plan in the Admin Panel
1. Log into the Admin Dashboard (`mocktest-admin`).
2. Go to **Commerce > Subscription Plans** (`/admin/commerce/subscription-plans`).
3. Click **Create Plan**.
4. Select the target course (e.g., your test course).
5. Enter:
   - **Name:** "Test Monthly Pass"
   - **Billing Cycle:** `Monthly`
   - **Duration:** `30` days
   - **Price:** e.g., `49` (or `499`)
   - **Is Active:** `true`
6. Click **Save**.
7. From the database or admin table, obtain the generated `plan_id` UUID (e.g., `6995d41d-7704-457b-b82c-47ceff0b1a10`).

### Step 2: Create the Subscription Product in Google Play Console
1. Open **Google Play Console > Monetize > Products > Subscriptions**.
2. Click **Create subscription**.
3. **Product ID:** Enter `sub_` followed by the 32 clean hex characters of `plan_id` without dashes:
   *(Example: `sub_6995d41d7704457bb82c47ceff0b1a10`)*.
4. **Name:** "Test Monthly Pass".
5. Click **Create**.

### Step 3: Configure the Base Plan
1. In the newly created subscription product, scroll to **Base plans** and click **Add base plan**.
2. **Base Plan ID:** Enter `p1m`.
3. **Type:** Select **Auto-renewing**.
4. **Billing period:** Select **1 month**.
5. **Grace period:** Select **7 days** (aligns with backend `grace_end_date`).
6. **Customer changes:** Select "Charge immediately".
7. **Prices:** Set price to match the admin panel (e.g., ₹49.00 or ₹499.00).
8. Click **Activate base plan**.

### Step 4: Create and Activate an Offer
1. Under the `p1m` Base Plan, click **Add offer**.
2. Choose **Standard** (available to all users / default offer).
3. Click **Activate offer**.
   *(Critical: react-native-iap 15.6.2 requires an active offer token to launch Google Play checkout).*

### Step 5: Test on Device with License Tester Account
1. Ensure your Google account is added as a **License tester** under **Play Console > Setup > License testing**.
2. Ensure License test response is set to `RESPONDS_NORMALLY`.
3. Open Make Me Topper on the test device, logged into the app.
4. Open the course page. The subscription plan will appear in the plan list.
5. Tap **Enroll / Subscribe**. Google Play checkout opens with "[Test Instrument]" card and test renewal frequency (renewals happen every 5 minutes in sandbox).
6. Complete purchase.
7. Verify that:
   - Google Play checkout finishes.
   - App logs show: `[PLAY_BILLING] Subscription purchase received`.
   - Supabase `verify-google-play-purchase` executes and returns HTTP 200.
   - Database has new rows in `student_subscriptions` and `course_enrollments` (`enrollment_type = 'subscription'`).
   - Course immediately unlocks.
